# Nexus Framework v0.1.0-rc.1

**Simple by default. Powerful by design.**

`v0.1.0-rc.1` is the first public release candidate of the Nexus v0.1 Foundation. It is intended for evaluation, integration testing and early adoption. It is not yet the final v0.1 production release, and pre-1.0 public APIs may still change.

## Highlights

- Progressive application architecture: start minimal and introduce modules, Hexagonal Architecture, DDD or CQRS only where needed.
- Small PHP core with optional capabilities and explicit lifecycle.
- Built-in PSR-11 dependency injection container.
- HTTP routing, middleware, REST helpers, validation and OpenAPI.
- Relational persistence for PostgreSQL, MySQL, SQLite, SQL Server and Oracle.
- ORM-independent migrations, Code First and basic Database First.
- Optional Eloquent integration.
- Optional MongoDB document adapter and repository facade.
- Cache, Redis abstractions, CQRS, synchronous events, seeders, factories and deterministic fake data.
- Optional Docker stacks for FrankenPHP, PHP-FPM + Nginx, RoadRunner and OpenSwoole.
- Quality gates on PHP 8.4 and PHP 8.5 with PHPUnit, PHPStan max, PER-CS, Composer Audit and benchmark smoke tests.

## Validation

The release candidate is validated through:

- PHP 8.4 and PHP 8.5 quality jobs;
- live PostgreSQL, MySQL, SQL Server and Oracle integration probes;
- SQLite in-memory integration tests;
- Docker Compose validation and image builds for FrankenPHP, PHP-FPM + Nginx, RoadRunner and OpenSwoole;
- clean Composer package-install smoke testing.

See `docs/SUPPORT_MATRIX.md` for the exact support and validation boundary of each capability.

## Important limitations

- MongoDB's official adapter is not yet exercised against a live MongoDB service in CI.
- Docker validation proves generated topology and buildability, not application-specific load or production deployment behavior.
- The gRPC project preset does not imply a native gRPC transport implementation in v0.1.
- Queue/async runtimes and RabbitMQ, Kafka or SQS messaging adapters are not part of this release candidate.
- Reporting and mail remain planned optional packages.
- Nexus Database Core supports Oracle, but Nexus does not claim native Eloquent-on-Oracle support.

## Installation

Until the package is indexed by Packagist, Composer can install the tagged repository through a VCS repository declaration. Once `nexus/framework` is available on Packagist, the intended installation is:

```bash
composer require nexus/framework:^0.1@RC
```

## Feedback

Please report reproducible bugs and compatibility problems through GitHub Issues. For support claims, use `docs/SUPPORT_MATRIX.md` as the canonical reference rather than the long-term roadmap.

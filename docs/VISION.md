# Vision

Nexus aims to combine a gentle learning curve, high productivity, progressive
architecture, real modularity, measurable performance and technological
flexibility in one modern PHP framework.

Simple applications should remain simple. Complex systems should be able to
grow toward modules, Hexagonal Architecture, DDD, CQRS, events, async, gRPC and
polyglot persistence without a traumatic rewrite.

## What Nexus avoids

- Empty architectural ceremony in a new project.
- Loading or installing unused components.
- Mandatory infrastructure dependencies.
- A core coupled to an ORM, Redis, MongoDB or a transport.
- Hidden magic that makes debugging difficult.
- Premature optimization without benchmarks.

The framework base will remain open source. Future ecosystem products may
include Nexus Studio, Cloud, Monitor and Architect, plus professional support,
consulting and training.
